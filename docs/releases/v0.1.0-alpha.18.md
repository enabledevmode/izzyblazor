Fixes for overlays and disclosures on interactive pages, tabs that scroll with a mouse wheel, and dialogs that keep their shape as they close. One parameter is gone: `DialogClose.Reset`.

## Breaking

- **`DialogClose` no longer takes `Reset`.** A reset button can't close a dialog (browsers ignore the close command on one, and the close form has nothing to reset), so it did nothing; it now throws. To reset a form as well, put a `Button` with `Reset` beside the `DialogClose`.

## Fixed

- **Quick opens and closes on interactive pages** end where the user left them, at any connection speed. Renders made before the user's latest change could arrive late and undo it: a Dialog or Drawer could open and close for ever, and an Accordion item double-clicked on a slow connection ended in the wrong state. The script and C# now count each change (`IzzyToggleEventArgs.Seq`, rendered as `data-ib-seq`), and a render that hasn't caught up is ignored. This covers Dialog, Drawer, Popover, Menu, Accordion and Collapsible.
- **Back or Forward with a dialog open** no longer leaves the page unresponsive. Enhanced navigation removed the dialog's `open` attribute without closing it, so it stayed modal, unseen; it's now closed properly.
- **Closing a dialog** no longer shrinks it to a line and re-centers it before it fades (most visible on phones). Safari and Firefox, which can't keep a closing dialog in the top layer, close it without the fade.
- Close buttons that submit the dialog's close form no longer carry the close command, which Chromium ignored and warned about in the console on every page with a dialog.

## Navigation

- **Tabs that don't fit** scroll with a mouse wheel (the strip hides its scrollbar), handing back to the page at either end. The selected tab is scrolled into view when the page loads, after enhanced navigation, and when C# or the URL changes it.
- **`FullWidth` tabs** keep equal widths but no narrower than their label, so they scroll instead of cutting labels off.

## Disclosure

- On interactive pages `AccordionItem` and `Collapsible` render `data-open` instead of `open`, and IzzyBlazor's script opens them, before the first paint. Static pages are unchanged. Styles that use `[open]` still apply.

## Docs site

- A demo's Desktop/Phone switch is hidden when the demo is narrower than 640px, where both looked the same.
- The Collapsible custom-trigger example keeps its width when it opens, so its trigger no longer moves from under the pointer.
