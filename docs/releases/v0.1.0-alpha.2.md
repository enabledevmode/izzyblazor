The styling API is settled: one name per idea, theming for part of a page, and colors that follow every override. This release renames things, and Razor accepts an old parameter name without complaint (it becomes an HTML attribute and does nothing), so check the list below when you update.

## Renamed

| alpha.1 | alpha.2 |
| --- | --- |
| `Color` on Button, IconButton, LinkButton, ConfirmButton | `Accent='Accent.Of("#0f766e")'` or `Accent.Token("success")` |
| `Color` on Badge, Tag, Banner, Progress | `Accent` (the same roles, or `Accent.Of` / `Accent.Token`) |
| `Color` on Avatar | `Accent`, plus `Variant` (`AvatarVariant.Soft` by default, or `Solid`) |
| `NavItem BadgeColor` | `BadgeAccent` |
| `Scheme` on Box, AppSidebar and other parts (`Scheme.Page`) | `ColorScheme` (`ColorScheme.Auto`, `Light`, `Dark`, `Inverse`) |
| `ColorScheme.System` | `ColorScheme.Auto` |
| `IzzyTheme Look` (`ThemeLook`) | `Preset` (`ThemePreset`) |
| `IzzyTheme Accent` (`ThemeAccent`) and `Primary` | `Brand`: a built-in name (`"teal"`) or a hex color |
| `IzzyTheme Gray` (`ThemeGray`) | `Gray`: a built-in name (`"stone"`) or a hex color for your page |
| `IzzyTheme Font` | `BodyFont` (with `HeadingFont`, `MonoFont`) |
| `FontFamily.Sans`, `FontFamily.Serif` | `FontFamily.Body`, `FontFamily.Heading` (and `Mono`) |
| `AccentPalette` | `BrandPalette` |
| `data-ib-theme`, `<meta name="ib-theme">` | `data-ib-preset`, `ib-preset` |
| `data-ib-accent`, `<meta name="ib-accent">` | `data-ib-brand`, `ib-brand` |
| `data-theme`, `<meta name="ib-scheme">` | `data-ib-color-scheme`, `ib-color-scheme` |
| `--ib-font-sans`, `--ib-font-serif` | `--ib-font-body`, `--ib-font-heading` |

`Accent="Accent.Danger"` and the other roles are written the same as before. `Skeleton Height` is now the shared `Height` style prop (it still takes a `Length`).

## New

- **Theming part of a page:** `<IzzyTheme Brand="#be123c" Density="ThemeDensity.Compact">…</IzzyTheme>` themes what's inside it, and takes `Class` and `Style` for exact CSS values. Dialogs opened from code can match it: `DialogOptions` takes `ColorScheme`, `Brand` and `Density`.
- **Your grays from one color:** `Gray="#f4efe6"` derives the page, surfaces, fills, borders and text in light and dark, with contrast checked (`GrayPalette`).
- **Radius** `None` and `Full` (pill buttons, fields, badges, tags and segmented controls).
- **Style props:** `Border`, `BorderX`, `BorderY`, `BorderTop`, `BorderBottom`, `BorderStart`, `BorderEnd`, `BorderColor`, `Height`, `MaxHeight`, `MinWidth`, `Overflow`.
- **Colors:** `Color.SuccessSoft`, `WarningSoft`, `DangerSoft`, `InfoSoft` and `Focus`.
- **Component variables** you can set anywhere, such as `--ib-btn-radius`, `--ib-btn-px`, `--ib-field-radius`, `--ib-card-padding` and `--ib-table-cell-px`; the full list and every token are in [docs/styling.md](https://github.com/enabledevmode/izzyblazor/blob/main/docs/styling.md).
- `AppBrand` for the header's name, `HideExternalIcon` on Anchor and LinkButton, and `VideoEmbed` without a `YouTubeId` for a video that isn't out yet.

## Fixed

- Focus rings, hover and pressed washes and selected rows follow a color override on part of a page, not just on the whole app.
- Inline components (Code, Anchor, Kbd, Badge, Tag) keep their natural width in a Column.
- Alert and Banner close with a real button when the script runs.
- Derived brand colors hold their contrast on every built-in gray set.

## Browsers

Browsers from 2024 on (`:has()`, popover, `light-dark()`). The fallback for older browsers is gone.
