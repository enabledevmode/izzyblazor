Toggle buttons and a `Toolbar` that drops its labels before anything moves into its menu. Also: enhanced navigation no longer flashes the old page from its top, a few accessibility fixes, and the documentation now lives only on [izzyblazor.com](https://izzyblazor.com).

## New

- **`Pressed` on `Button` and `IconButton`** makes a toggle button, such as Bold: screen readers hear "pressed" or "not pressed" (`aria-pressed`), and pressed it shows a tint and an edge in the accent's text color. With `@bind-Pressed` (`PressedChanged`) a click toggles it before `OnClick` on interactive pages; on static pages set it from the server's state and post the change with `Submit`, `Name` and `Value`. A link can't be pressed: `Pressed` with `Href` throws.
- **In a `Toolbar`'s "…" menu a toggle is a checkbox item** (`menuitemcheckbox`) that toggles the same.
- **`Toolbar CollapseLabels`**: before anything moves into the "…" menu, `ToolbarButton`s with a `StartIcon` (in a `ToolbarButtonGroup` too) show only their icon, and `ToolbarMenu`s with one keep their icon and chevron, all at once; items then move into the menu as before. The text stays for screen readers and, with script, is the tooltip. An item with `Overflow="ToolbarOverflow.Never"` keeps its text. It works with JavaScript off: the server adds one container query for it.

```razor
<Toolbar Label="Insert" CollapseLabels>
    <ToolbarButton StartIcon="Lucide.Heading">Heading</ToolbarButton>
    <ToolbarButton StartIcon="Lucide.List">List</ToolbarButton>
    <ToolbarIconButton Icon="Lucide.Bold" Label="Bold" @bind-Pressed="_bold" />
    <ToolbarButton StartIcon="Lucide.Send" Position="ToolbarPosition.End" Overflow="ToolbarOverflow.Never">Publish</ToolbarButton>
</Toolbar>
```

- `AppShellContext` carries the shell's `ScrollMode`.

## Changed (check when you update)

- **With `ShellScroll.Main`, `AppMain` is a tab stop** (`tabindex="0"`, was `-1`), so a main area that scrolls on its own can be scrolled from the keyboard when nothing in it takes focus. It shows a focus ring when the keyboard reaches it. With `ShellScroll.Page` nothing changes.
- **A tab's error count reads "Billing (1 error)"** (was "Billing, 1 error", which Chrome read as "Billing , 1 error").
- **A selectable `Table`'s checkbox column has a hidden "Select" heading** (`SelectRowLabel`) while select-all is hidden with no script; once the script runs, the select-all checkbox names the column as before.
- **`ColorPicker` with `ShowHex="false"`** is a square swatch, with or without script, instead of a full-width box with an empty stretch.
- **`docs/getting-started.md`, `docs/styling.md` and `docs/components.md` are gone** from the repository: the same documentation, kept up to date, is on [izzyblazor.com](https://izzyblazor.com).

## Fixed

- **Enhanced navigation no longer shows the old page from its top** while the next one loads. Since .NET 10, Blazor scrolls to the top as soon as a link to another page is followed, before the response arrives ([dotnet/aspnetcore#64015](https://github.com/dotnet/aspnetcore/issues/64015)); IzzyBlazor's script keeps the page where it is and goes to the top (or the link's `#fragment`) once the new page is in. Interactive routing and `NavigationManager.NavigateTo` are unchanged.
