Buttons submit with a bare `Submit`: `<Button Submit>Save</Button>`. One rename.

## Changed (check when you update)

- **`Type` and `ButtonType` are gone from `Button`, `IconButton` and `MenuItem`: use `Submit`, or `Reset` on buttons.** Write `<Button Submit>` for `<Button Type="ButtonType.Submit">`, `<Button Reset>` for `ButtonType.Reset`, and drop `Type="ButtonType.Button"` (a button that does nothing by itself is still the default). Setting both `Submit` and `Reset` throws. The old names don't compile, so the build points at each place to change. This also ends a false "Wrong attribute value" warning in Rider and ReSharper, which checked `<Button Type="...">` against HTML's `<button type>`.
