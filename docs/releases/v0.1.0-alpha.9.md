Buttons submit with a bare `Submit`: `<Button Submit>Save</Button>`. One rename.

## Changed (check when you update)

- **`Type="ButtonType..."` on `Button`, `IconButton` and `MenuItem` is replaced by `Submit`, or `Reset` on buttons.** Write `<Button Submit>` for `<Button Type="ButtonType.Submit">`, `<Button Reset>` for `ButtonType.Reset`, and drop `Type="ButtonType.Button"` (a button that does nothing by itself is still the default). Setting both `Submit` and `Reset` throws.
- **Old markup fails to build.** `Type` and `ButtonType` stay for this release, marked obsolete as errors, so every old use stops the build with error CS0619 and a message pointing to `Submit`. (Without them, Razor would take `Type="ButtonType.Button"` as a plain HTML attribute, and the browser would treat that button as a submit button.) They'll be removed in a later release.
- This also ends a false "Wrong attribute value" warning in Rider and ReSharper, which checked `<Button Type="...">` against HTML's `<button type>`.

## Fixed

- `<DialogClose Reset>` threw "can't set both Submit and Reset" (a `DialogClose` submits its close form by default); it now resets the form instead.
- The error for setting both `Submit` and `Reset` names the component used (`DialogTrigger`, `DialogClose`), not `Button`, and is raised while the button is loading too.
