`izzy list`, `izzy describe` and `izzy add` now name an item by its kind and its id, as `izzy new` does.

## CLI

- **Breaking: the kind is a word in `add`, `describe` and `list`.** `izzy add hero` is now `izzy add block hero`, and `izzy describe hero` is `izzy describe block hero`. Starters and kits are described the same way: `izzy describe starter sidebar`, `izzy describe kit crm`. The old form answers with the command to type.
- **Breaking: `izzy list --kind block` is `izzy list block`.** `izzy list` alone still lists everything.
- `izzy add crud <Model>`, `izzy describe crud`, `izzy describe init` and `izzy new starter|kit <id>` are unchanged.
- **`izzy mcp`:** `describe_item` and `add_item` take a `kind` with the item's id.
- **Components in `izzy`:** `izzy list component` lists the library's components, and `izzy list` names them after the catalog's items. `izzy describe component DataGrid` lists a component's options, content, events and examples; with `--json` the options are a JSON Schema, as a block's settings are. `izzy describe component --all --json` gives every component and part in one answer, for an editor.
- **`izzy add component <Name> --at <file>:<line>`** puts a component's usage example from the docs on a page: its markup at the line, its `@using` lines at the top, its `@code` members in the page's `@code` block. A name the page already has gets a number (`Model2`). `--example <name>` takes another example, and `--tag` adds the tag alone, at a column too (`--at <file>:<line>:<col>`).
- **For editors:** `izzy inspect <file>:<line>:<col> --json` gives the component at a position and what each attribute says (a free account). `izzy set <file>:<line>:<col> --<option> <value>` changes an option, and `--unset <option>` removes one (IzzyBlazor Pro). These and `add component` read the page from standard input with `--stdin`.
- **`izzy mcp`:** `list_items`, `describe_item` and `add_item` take components (`kind: "component"`).
- `izzy list` groups its items under a heading for each kind: starters, kits, blocks, then the components.

## Fixes

- **DataGrid:** with `SelectOnClick` and one row selected at a time, Tab into the grid landed on the row's hidden radio. It now lands on the first cell.

- **Accessibility, from an axe-core run over the docs, the starters and Izzy CRM:**
  - A chart's range buttons are named for what they show and what it means ("3M, Last 3 months"), so voice control finds them by the text on the button.
  - The Scheduler's Today button is named with the date ("Today, November 23"), which is what it shows on a phone.
  - A Badge in a solid Banner is a pill of the banner's text color with dark text; it was white on a pale wash, 3.6:1.
  - A chart legend entry that is switched off is struck through in the muted text color. Only its color key fades.
  - A code block in Markdown or RichText output takes keyboard focus, so it can be scrolled sideways without a mouse.

## Docs

- A component's page shows the `izzy add component` command under its usage example.
- Accessibility fixes from an axe-core run over every page: scrolling tables and diagrams take keyboard focus, the "From" links on API pages are underlined, and section pages' cards are level 2 headings.
