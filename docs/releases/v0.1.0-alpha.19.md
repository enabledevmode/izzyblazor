Tabs that don't fit scroll by swipe on touch screens, and the docs site has more examples and five more hand-written Overviews. No API changes.

## Fixed

- **Tabs that don't fit** scroll by swipe on phones and tablets. A swipe that started on a tab didn't move the strip (a mouse wheel and TabLinks did), for horizontal tabs and for vertical tabs, which are a row on phones. Each tab's label is now a box of its own rather than `display: contents`; tabs look and click the same.

## Docs site

- **Examples:** OnThisPage has a demo, a guide with its outline beside it; PrevNext, Container and AspectRatio have a second example each. Every component now has at least two.
- **Overviews:** Badge, Progress, CopyButton, Fieldset and OnThisPage have hand-written Overviews.
- **Search** no longer lists headings from an Overview's Usage sample as sections of the page.
- **Crawlers** are kept off query-string addresses (`robots.txt`), and one client is held to 60 pages a minute, after a crawler walking the Pagination examples slowed every page.
