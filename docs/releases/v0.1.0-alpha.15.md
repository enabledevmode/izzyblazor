`Highlight` marks the words of a search in text, and `Heading.SlugOf` gives the id a heading gets, both built for the new search on [izzyblazor.com](https://izzyblazor.com). The docs site also gets search (Ctrl+K), a sitemap and canonical links for search engines.

## New

- **`Highlight`** shows text with each word of a query in a `mark`, for search results, a filtered list or a table filtered by a `FilterForm`. A word matches at the start of a word, the humps of a PascalCase name included ("field" marks the "Field" of "TextField"), or anywhere with `Match="HighlightMatch.Anywhere"`; case is ignored and touching matches are marked as one. `Highlight.Find` gives the ranges for your own markup. It works the same in every mode.

```razor
<Highlight Text="@product.Name" Query="@Query" />
<Highlight Text="@product.Description" Query="@Query" Match="HighlightMatch.Anywhere" />
```

- **`Heading.SlugOf(text)`** returns the id a heading with that text gets once an `OnThisPage` lists it ("Rows & columns" is "rows-columns"), for linking to a section from another page.

## Docs site

- Search: the header's Search button or Ctrl+K opens results as you type, across components, parameters, articles, sections and demos; `/search` works with JavaScript off.
- Off pages read the production stylesheet's no-script rules again (the minified `@media (scripting: none)` rules were dropped, so the Slider's fill and the Alert's close buttons were wrong in Off mode).
- `robots.txt`, `sitemap.xml`, a canonical link on every page (without `?mode=` and other queries), Open Graph titles, descriptions and addresses, and shorter descriptions.
