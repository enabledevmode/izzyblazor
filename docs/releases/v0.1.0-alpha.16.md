The surface colors are renamed by what they do: an overlay floats above the page, and fills inside a surface go from subtle to strong in light and dark mode. Stepper gets a compact row on phones, SiteNav's menu button can sit at the start of the header, and a TabLink can be marked current whatever the URL. The docs site gets an MCP server for AI assistants.

## Changed (check when you update)

Razor takes an old parameter name silently, so search your project for each of these.

- **Surface colors** (C# and CSS variables; a custom theme that sets the variables must rename them too):
  - `Color.SurfaceRaised` → `Color.SurfaceOverlay`; `--ib-color-surface-raised` → `--ib-color-surface-overlay`; `--ib-color-raised-border` → `--ib-color-overlay-border`
  - `Color.SurfaceContainerLow` → `Color.FillSubtle`; `--ib-color-surface-container-low` → `--ib-color-fill-subtle`
  - `Color.SurfaceContainer` → `Color.Fill`; `--ib-color-surface-container` → `--ib-color-fill`
  - `Color.SurfaceContainerHigh` → `Color.FillStrong`; `--ib-color-surface-container-high` → `--ib-color-fill-strong`
- **`SiteNav.MenuButtonAtEnd`** is replaced by `MenuButtonPosition`: `MenuButtonAtEnd="false"` is now `MenuButtonPosition="MenuButtonPosition.InPlace"`; the default, `End`, is unchanged.

## New

- **`SiteNav.MenuButtonPosition`**: `End` (the default), `Start`, before the brand, to match pages whose header starts with a `SidebarToggle`, or `InPlace`, where the links are. Start and End move the button visually, so Tab still reaches it where the SiteNav is written.
- **`TabLink.Current`** marks a tab current (`true`) or not (`false`) whatever the URL, for a choice the page knows from elsewhere, such as a cookie. When one tab is set current, the tabs that follow the URL are unmarked; it renders `aria-current="true"`, and a disabled tab is never current.

```razor
@* The billing period comes from a cookie, so the address can't tell which tab is current. *@
<Tabs Label="Billing" Variant="TabsVariant.Segmented">
    <TabLink Href="pricing?billing=monthly" Label="Monthly" Current="@(Billing == "monthly")" />
    <TabLink Href="pricing?billing=yearly" Label="Yearly" Current="@(Billing == "yearly")" />
</Tabs>
```

## Layout

- **Stepper on phones:** below 640px a horizontal stepper is a row of markers with only the current step's label, instead of a column; a finished step with an `Href` is still a link on its marker, with the focus ring there. `Orientation.Vertical` is unchanged.
- **AppSidebar:** a collapsible sidebar's labels stay on one line from its breakpoint up, so they don't wrap while the width animates; a label too long for the sidebar ends in an ellipsis.
- **AppShell Inset:** beside a sidebar (from its breakpoint up) the main panel has no gap of its own on that side, so an icon rail sits centered in its column.
