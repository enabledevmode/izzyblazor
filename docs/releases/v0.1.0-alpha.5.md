`FileUpload` now reads as one call to action, "Choose a file or drag it here", with the types and size it takes shown under it, instead of the browser's own "Choose File" button and "No file chosen". Borders can be dashed or dotted with the new `BorderStyle`. FileUpload's prompt parameter and its `IzzyText` strings are renamed, so check the first section when you update.

## Changed (check when you update)

- **FileUpload's prompt is renamed.** `PromptText` is now two parameters: `ChooseText`, the link that opens the picker ("Choose a file"), and `DragText`, the text after it ("or drag it here"). Razor passes an unknown parameter through as an HTML attribute, so an old `PromptText="…"` doesn't fail: it lands on the `<input>` and the zone shows the default text. Search for `PromptText` when you update.
- **`IzzyText` strings for FileUpload are renamed.** `DropFile` and `DropFiles` ("Drag a file here, or") are replaced by `ChooseFile` ("Choose a file"), `ChooseFiles` ("Choose files"), `DragFileHere` ("or drag it here") and `DragFilesHere` ("or drag them here"). A subclass that overrides the old ones no longer compiles.
- **The zone looks different.** It's filled with the container-low color, its icon is Lucide `Upload` (an arrow out of a tray) in a circle, where it was `CloudUpload`, and "Choose a file" is an underlined link in the accent color. An `IconSet` that maps `IconRole.Upload` keeps its own icon. Set `--ib-upload-bg` to go back to the plain surface.
- **The browser's file button is gone.** "Choose a file" is a `<label>` for the input, so it opens the picker with JavaScript off too. While scripts run the input is hidden but still focusable, and the zone shows its focus ring; without them the input shows only the browser's file name ("No file chosen", then the file picked). With the script, the chosen file's name and size, or "3 files", replace the hint.
- **Rendered output** of `FileUpload` changed; only tests that compare its markup notice.

## New

- **`BorderStyle`** on `Box` and every component built on it: `Solid` (the default), `Dashed`, `Dotted` or `None`, and it can change by breakpoint. It draws the borders you set with `Border`, `BorderX`, `BorderY` and the single sides: `<Box Border="1" BorderStyle="BorderStyle.Dashed">`, or `<Section BorderY="1" BorderStyle="BorderStyle.Dotted">`. On its own it restyles the built-in border of a `Card` (`<Card BorderStyle="BorderStyle.Dashed">` for an "add new" tile) or a `Bordered` `EmptyState`; on other components it needs a `Border` width.
- **FileUpload's hint comes from `Accept` and `MaxFileSize`**: `Accept=".png,.jpg" MaxFileSize="2_000_000"` shows "PNG or JPG · up to 2 MB". Types are listed only when each has a plain name, so `"image/*"` shows just the size. Screen readers hear it with the field. `AcceptText` still replaces it, and `AcceptText=""` hides it.
- **FileUpload variables**: `--ib-upload-bg` (the zone's fill), `--ib-upload-border-color` and `--ib-upload-border-style` (dashed by default), on `:root` or any element.
- **`HideLabel` on `FileUpload`**, as on the other fields.
- **New `IzzyText` strings**: `FileSizeLimit` ("up to {0}"), `ListOr` ("or", in "PNG, JPG or GIF") and `FilesChosen` ("{0} files").

## Fixed

- With JavaScript off, FileUpload no longer invites dropping a file: nothing handles a drop without the script, so the browser opened the file in place of the page. On touch screens the zone shows only the link as well.
- A FileUpload with errors keeps its danger border and halo when it has keyboard focus, as other fields do.

## Size

The script grows by about 70 bytes gzipped.
