Layout props now work on almost every component, not just boxes. A field, a button or a menu can grow in a row, take a margin or a width, and line itself up with `AlignSelf`, and `Style` on a field or `FileUpload` finally reaches the element the row lays out. Nothing is renamed, but a few attributes that used to pass through to an element now bind to a parameter, so check the first section when you update.

## Changed (check when you update)

- **`Style` on a field goes on the field, not the input.** On `TextField`, `TextArea`, `Select`, `Combobox`, `MultiSelect`, `NumberInput`, `Slider`, `ColorPicker`, `Checkbox`, `Switch`, `RadioGroup`, `CheckboxGroup` and `SegmentedControl`, `Style` (or `style`: Razor matches parameter names in any case, and a `"style"` key in `@attributes` too) used to reach the native `<input>`, `<select>` or `<textarea>`. It now goes on the wrapper around the label, control and hint, like `Class` always has, so `flex-grow` and margins work. To style the control itself, use a class and CSS: `.search .ib-field-input { … }`.
- **`width="…"` is a compile error** on fields and on the components that now take layout props (listed below). It used to pass through as an HTML attribute; it now binds to the `Width` parameter, which takes a `Length`: `Width="Length.Px(200)"`, or `Width="15.Rem"` with `@using IzzyBlazor.Units`.
- **Rendered output** is the same as before until you set a layout prop. Once you do, the component gets the layout classes (`ib-grow`, `ib-mx` and the rest) and their custom properties, such as `ib-btn ib-grow ib-btn-primary ib-btn-solid`; only tests that compare a whole `class` attribute notice.

## New

- **Layout props on most components.** `Margin` (with `MarginX`, `MarginY` and each side), `Width`, `MinWidth`, `MaxWidth`, `Grow`, `Shrink`, `Basis` and the new `AlignSelf` now work on fields and `FileUpload`, every button and `ButtonGroup`, `Alert`, `Badge`, `Banner`, `Progress`, `Spinner`, `Tag`, `Avatar`, `AvatarGroup`, `Stat`, `Table`, `Accordion`, `AccordionItem`, `Collapsible`, `Form`, `FilterForm`, `Tabs`, `Breadcrumb`, `Pagination`, `Stepper`, `NavMenu`, `SiteNav`, `AppBrand`, `ColorSchemeSwitch`, `SidebarToggle`, `Code`, `Kbd`, `Anchor`, `Menu`, `Popover` and `Tooltip`. They go on the element the parent lays out: `<TextField @bind-Value="Query" Grow />` next to a button, `<FileUpload Name="Photo" Grow />` next to an avatar.
- **`AlignSelf`** overrides the parent's `Align` for one item, on these components and on `Box` and everything built on it: `<Button AlignSelf="Align.End">` lines up with the bottom of labeled fields.
- **`HiddenFrom` and `VisibleFrom` on fields.**
- **Menu, Popover and Tooltip** take the layout props on the element around the trigger; `Grow` or `Width` stretches the trigger, and the panel lines up with it. `Class` and `Style` still style the panel.
- **`PanelWidth`** on `Menu` and `Popover` sets the panel's width, such as `Length.Rem(32)` for a filter form, past the 24rem default. It never gets wider than the screen.
- **`Width` on `Dialog` and side `Drawer`** for a width the sizes don't cover; it can change per breakpoint and keeps the size's margin on small screens. A dialog isn't laid out in the page, so margins, `MinWidth`, `MaxWidth` and the flex props throw on it, with a message that points to `Size` and `Width`.
- **`ContentPadding`** on `Dialog` (the body) and `Tabs` (every panel; a `Tab` can set its own). `0` runs a table or image edge to edge, as on `Accordion`.
- **`MaxHeight` on a `Code` block**: the code scrolls, and the language label and copy button stay in place.
- **`Fieldset`** takes the style props, so `Border="1" Padding="4" Radius="Radius.Md"` draws a boxed group.
- **For your own components:** `LayoutItemBase` is the base for components that sit in a layout (item props only); `StyledComponentBase` now builds on it and adds the surface props. `ToggleComponentBase` builds on it too. A component whose `Class` goes on an inner element (`VisibilityOnRoot => false`) puts the layout props on its outer element with `BuildOuterAttributes`.

## Fixed

- `Style` on `FileUpload` was dropped; it now goes on the field, as on other fields.
- Docs: the `ColorSchemeSwitch` values are `Auto`, `Light` and `Dark` (there is no `ColorScheme.System`), the presets list Inter as their font, and `FieldFrame` is documented. Three variables (`--ib-control-icon-stroke-sm`, `--ib-sidebar-w`, `--ib-aside-w`) are no longer listed: nothing reads the first, and the others are set from `AppSidebar Width` and `AppAside Width`.
