Nine new components (TreeView, PickList, Autocomplete, Rating, PinField, QrCode, Barcode, Splitter and Carousel), option groups, chips, a floating action button, password requirements, and row reordering in the DataGrid. Combobox and Autocomplete now search the server as you type on static pages. Timing parameters are `TimeSpan`s, so check the Breaking list before upgrading.

## Breaking

- **Timing parameters take a `TimeSpan`, not milliseconds:** `Combobox.Debounce` and `Autocomplete.Debounce` (250 ms by default), `ToastRegion.Duration` (5 seconds), `ToastMessage`'s `Duration` and `ToastService.Show`'s `duration`, and `Tooltip.Delay` (300 ms). Write `Delay="TimeSpan.FromMilliseconds(150)"` for `Delay="150"`, and `Duration="TimeSpan.Zero"` for `Duration="0"`, which still keeps toasts open.

## New components

- **TreeView**: nested items from data (`Items`, `ItemChildren`), as links or with selection (`SelectionMode`, `@bind-Selection`, `Cascade`), keyboard navigation, branches that open with no script and stay open across pages, children that load when a branch opens (`ChildrenProvider`, on static pages too), and a search box.
- **PickList**: choose items by moving them from Available to Chosen, in order, with buttons, keys or a drag. It posts with no script.
- **Autocomplete**: a text field that suggests from `Items`, `Search` or `ItemsProvider`; anything typed is the value.
- **Rating**: stars on native radios, and `ReadOnly` shows any value, fractions too.
- **PinField**: a short code in boxes over one real input, so paste, autofill and screen readers work as in a text field.
- **QrCode** and **Barcode** (Code 128, EAN-13, EAN-8, UPC-A), drawn on the server as SVG, with no package.
- **Splitter**: panes with bars that resize them by dragging or arrow keys, collapsible panes, and sizes kept per person (`LayoutKey`) and drawn by the server on the next visit.
- **Carousel**: slides on the browser's own scroller, so they swipe with no script; previous and next buttons, dots on the slide or below (`Dots`), several slides at once per breakpoint (`ItemsPerView`), `Loop`, `@bind-Index`, `Autoplay` with a button to stop it, and a `Fade` transition. With reduced motion, the buttons and dots move without sliding and autoplay starts stopped.

## Other changes

- **Option groups:** `ItemGroup` on Select, Combobox and MultiSelect; an enum's groups come from `[Display(GroupName)]`.
- **Chips:** CheckboxGroup and RadioGroup can show their options as pills (`Chips`), still native checkboxes and radios.
- **Floating** on Button and IconButton fixes it to a corner of the window, a floating action button (`FloatPosition`).
- **Passwords:** a password TextField says when Caps Lock is on, and `Requirements` (a `PasswordRules`, named as Identity's options) lists the rules under the field, ticks each off as you type, and the form checks them on the server too.
- **Combobox and Autocomplete search the server as you type on static pages**: each pause in typing fetches the page with the typed text, and the field takes the answered suggestions in.
- **DataGrid** rows reorder by a handle (`ReorderableRows`), with a menu of moves and Alt+arrow keys, in every mode; with no script the moves post.
- ListView's and DataGrid's reordering events no longer bubble to an outer component on interactive pages (their `stopPropagation` never took effect before).
- Tooltip, dismissible messages, Banner, SiteNav and ColorSchemeSwitch load their code on demand, so the script every page loads is smaller.
- New `IconRole.Pause`, and `IzzyText` strings for the new components.
